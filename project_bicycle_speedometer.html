Technical Overview

A custom Hall-effect sensor array engineered for sub-millisecond velocity tracking. Originally developed for competitive cycling telemetry, this system provides unprecedented accuracy compared to standard reed-switch sensors.

Sensor Fusion Logic

Explaining how the Hall-effect signals are processed to eliminate noise and bounce. The system uses a dual-window comparative threshold to distinguish between magnetic interference and actual wheel rotation events. 

// Signal Processing Loop
void processHallArray() {
  uint32_t currentMicros = micros();
  int rawSignal = analogRead(SENSOR_PIN);
  
  // Dynamic threshold adjustment
  if (rawSignal > noiseFloor + hysteresis) {
    if (!signalDetected) {
      calculateVelocity(currentMicros - lastEvent);
      lastEvent = currentMicros;
      signalDetected = true;
      triggerStatusLED(1);
    }
  } else if (rawSignal < noiseFloor) {
    signalDetected = false;
  }
}

Circuitry & Prototyping

Developed and refined at the Kyoto Institute of Technology (KIT) labs, the project underwent three major hardware iterations. Initial breadboard prototypes proved the logic, while final versions utilized custom PCBs to handle high-vibration environments.

The integration of I2C displays allowed for real-time visualization of RPM, Average Speed, and Total Distance without taxing the main processing loop's timing accuracy.
