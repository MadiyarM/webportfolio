HonestRE Bot

Telegram WebApp + Bot for residential-complex reviews with moderation, ranking, geosearch, and RAG summaries

🚀 Production Status

Project Overview

HonestRE Bot is a production-ready Telegram bot that helps residents search for residential complexes, submit reviews, and enables administrators to moderate content with built-in anti-spam protection.

Key Features

🔎

Smart Search

Search complexes by name using Levenshtein algorithm with fuzzy matching capabilities

🚦

Rate Limiting

Built-in anti-spam and rate limiting to prevent abuse and ensure quality

🔗

WebApp Integration

Seamless hand-off to WebApp for richer UI and enhanced user experience

⚡

Fast & Minimal

Designed for noisy, real-world input with fast, minimal UX optimized for mobile

User Journey

1. Start & menu - Clean interface with main options
2. Search results - Fuzzy search with Levenshtein algorithm
3. Complex card - Details and recent reviews
4. Add review - Rating and text input
5. Confirm & submit - Review confirmation workflow
6. WebApp hand-off - Richer UI for detailed interaction
